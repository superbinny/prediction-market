## API 接口

| API                     | 用途                                         | 基础 URL                                         |
| ----------------------- | -------------------------------------------- | ------------------------------------------------ |
| **Gamma**               | 事件、市场、评论、个人资料、标签、系列和搜索 | <PublicRuntimeServiceUrl service="gamma" />      |
| **CLOB**                | 订单簿、价格、认证、订单、取消和账户交易     | <PublicRuntimeServiceUrl service="clob" />       |
| **Data**                | 仓位、活动、持有者、排行榜和分析             | <PublicRuntimeServiceUrl service="data" />       |
| **CLOB WebSocket**      | 公共市场和认证用户流                         | <PublicRuntimeServiceUrl service="wsClob" />     |
| **Live Data WebSocket** | 活动、评论和实时价格主题                     | <PublicRuntimeServiceUrl service="wsLiveData" /> |

## 认证

公共发现、订单簿、定价和大多数分析端点不需要
凭证。私有 CLOB 操作使用：

1. **L1 认证** — 一个钱包签名，证明对地址的控制并
   创建或派生凭证。
2. **L2 认证** — API 密钥、密钥和密码短语，用于签名私有请求。

订单提交还需要订单本身被签名。

<Callout type="info">
  如果你的语言受支持，从 SDK 开始。它处理凭证派生、请求签名和类型化负载 同时使用此处记录的相同 API。
</Callout>
