<SiteName /> 是一个点对点预测市场。交易员购买和出售结果份额，每份份额的价格反映了市场对该结果发生概率的当前估计。

## 预测市场如何运作

每个预测都分为三个部分：

| 部分                | 含义                                 |
| ------------------- | ------------------------------------ |
| **事件（Event）**   | 一个主题，用于分组一个或多个相关问题 |
| **市场（Market）**  | 一个你可以交易的问题                 |
| **结果（Outcome）** | 你购买或出售的侧面，例如"是"或"否"   |

结果份额的交易价格介于 **$0.00 到 $1.00** 之间。价格为 **$0.37** 的"是"份额代表约 **37%** 的隐含概率。

## payout

当市场达到最终结果时：

- 获胜份额结算为每份 **$1.00**。
- 失败份额结算为 **$0.00**。
- 你可以持有直到结算，也可以在结束前出售。

<Callout type="info">市场价格不是保证。它会随着交易员下单和成交而变化。</Callout>

## 完成你的第一笔交易

1. 创建你的账户并连接钱包。
2. 为你的交易余额充值。
3. 打开一个市场，选择一个结果，在签名前审查订单。
