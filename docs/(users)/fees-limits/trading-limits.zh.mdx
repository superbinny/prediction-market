title: 限制
description: 审查订单最小值、余额检查和提供商特定限制
---

应用在签名前强制执行订单阈值。资金提供商可以应用单独的
最小值、最大值、费用和区域限制。

## 交易阈值

| 规则           | 当前应用行为               |
| -------------- | -------------------------- |
| 市价买单最小值 | $1.00                      |
| 限价订单最小值 | 0.01 份额                  |
| 最大买入       | 可用余额和可执行流动性     |
| 最大卖出       | 可用份额，未承诺给开放订单 |

<Callout type="info">部署或市场可能暴露额外的约束。订单面板显示当前交易的有效最小值和最大值。</Callout>

## 存款和提现

审查所选钱包桥接、加密购买或转账路由的转账模态框。
提供商限制可能因资产、网络、付款方式、账户和区域而异。

## CSV 导出

**投资组合 → 历史记录** 导出当前包含在过滤器中的行。在下载文件前调整
日期、类型、搜索和排序选项。
