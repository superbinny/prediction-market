---
title: 领取你的收益
description: 在市场达到最终结果后赎回获胜仓位
---

import { Steps, Step } from 'fumadocs-ui/components/steps'

只有在市场达到最终结果后才能领取。每份获胜份额可兑换 $1.00；失败份额兑换 $0.00。

<Steps>
  <Step>
    ### 确认最终结果

    打开市场并验证时间线显示最终结果。

  </Step>
  <Step>
    ### 开始领取

    使用**投资组合（Portfolio）**中的领取卡片或已解析市场面板中的**领取收益（Claim winnings）**。

  </Step>
  <Step>
    ### 签名并确认

    审查包含的仓位，签名领取请求，等待确认。

  </Step>
  <Step>
    ### 检查余额

    领取的金额变为可用于下一笔交易或提现。

  </Step>
</Steps>

<Callout type="info">在领取之前，必须完成一次性存款钱包和授权设置。</Callout>

有关争议状态、收益示例和故障排除，请参阅
[解析与结算](/zh/docs/resolution-settlement/market-resolution)。
