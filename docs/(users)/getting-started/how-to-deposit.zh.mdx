在页眉中打开**充值（Deposit）**以查看你的运营商启用的充值方式。可用性、支持的资产、最小金额和处理时间可能因部署而异。

## 充值方式

| 方式                           | 用途                                      |
| ------------------------------ | ----------------------------------------- |
| **钱包（Wallet）**             | 从已连接的钱包桥接支持的资产              |
| **购买加密货币（Buy Crypto）** | 通过集成的卡或银行提供商购买资金          |
| **转账资金（Transfer Funds）** | 在 Polygon 上将 USDC 发送到显示的存款地址 |

## 存款

<Steps>
  <Step>
    ### 选择一种方式

    在存款模态框中选择钱包、购买加密货币或转账资金。

  </Step>
  <Step>
    ### 验证路径

    确认代币、网络、目标地址、预期金额和提供商费用。

  </Step>
  <Step>
    ### 提交

    批准钱包交易或完成提供商流程。

  </Step>
  <Step>
    ### 等待入账

    保留交易哈希或提供商引用，直到交易余额更新。

  </Step>
</Steps>

<Callout type="warning" title="检查代币和网络">
  仅发送当前存款流程中显示的资产和网络。不支持的资产或错误网络上的转账可能无法恢复。
</Callout>

对于直接转账，使用模态框显示的 exact USDC 代币。测试部署可能显示水龙头（faucet）而不是生产充值路由。
