title: 通知
description: 控制你部署中可用的交易和解析警报
---

打开 **设置 → 通知**。每个切换开关在更改时保存。

## 可用偏好设置

| 偏好设置              | 通道                 |
| --------------------- | -------------------- |
| 关注交易员活动        | 浏览器或已安装的应用 |
| 订单成交              | 应用内               |
| 市场解析              | 电子邮件             |
| 市场解析              | 应用内               |
| 隐藏小于 1 份额的成交 | 应用内过滤器         |

## 关注交易员活动

打开**关注交易员活动**以接收你关注的人在网站上交易时的交易警报。你也可以
从此页面打开**管理关注的交易员**以审查你关注的人或取消关注某人。取消关注交易员
也会停止他们的交易警报。

你的浏览器或设备可能会在这些警报出现前请求权限。在 iPhone 或 iPad 上，你可能需要先将
网站添加到主屏幕。

你的运营商可能启用不同的通道集。浏览器、设备和邮件提供商
设置也会影响传递。

<Callout type="info">通知是便利功能，不替代监控开放订单、解析截止时间或争议 窗口。</Callout>
