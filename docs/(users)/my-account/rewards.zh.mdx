打开 **[设置 → 奖励](/zh/settings/rewards)** 以查看推荐收入和通过报告
市场结果获得的奖励。每个程序都有自己的可用余额、终身收入和
**领取**操作。

## 推荐奖励

分享你的推荐链接或创建可嵌入的市场小部件。当归因的
用户交易时，你的配置的合格交易费份额作为推荐收入
credited 为推荐奖励。

|              |                  当前价值 |
| ------------ | ------------------------: |
| 合格费用份额 | <AffiliateShareDisplay /> |

推荐卡片显示推荐人、归因交易量、当前费用份额和最近的
推荐。佣金从合格交易费计算，而非直接从原始
交易量计算。

## 解析奖励

符合条件的用户可以从其解析模态框报告市场的可验证结果。
报告需要确认前显示的债券，每个存款钱包可以
每个市场提交一次。

- 正确的报告返回债券并 credited 配置的奖励。
- 错误的报告没收债券。
- 可领取的债券和奖励余额在钱包领取前保持可用。

解析活动卡片显示风险债券、正确和错误报告、准确率
和最近的提案。选择返回到其市场。

有关完整的报告、提取和安全储备规则，请参阅
[DRO 市场解析](/zh/docs/resolution-settlement/market-resolution)。

## 收入历史和领取

使用图表比较过去 30
天的推荐佣金和解析奖励。当任一余额可用时，在相应的卡片中选择**领取**并
签名钱包请求。

<Callout type="info">链上结算和索引活动可能在不同时间更新。一个完成的领取可能需要短时间才能 在活动视图中出现。</Callout>
