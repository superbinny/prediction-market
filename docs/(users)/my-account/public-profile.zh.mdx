你的公共资料可在 **/@username** 访问，并可从
**设置 → 查看公共资料** 打开。

## 公开信息

根据部署和你的可见性设置，页面可以显示：

- 用户名、头像和加入日期；
- 投资组合性能摘要；
- 公开仓位；
- 最近的公开活动。

<Callout type="warning">即使个人资料字段或平台视图隐藏，公共区块链活动仍可能与你的钱包相关联。</Callout>

使用 [个人资料设置](/zh/docs/my-account/profile-settings) 更新你的标识并
预览结果。
