使用你的运营商配置的支持渠道。完整的初始消息减少
后续跟进并使命题或市场问题更容易追踪。

<DiscordLink>打开支持</DiscordLink>

## 包含这些详情

- 你对期望结果的简短描述和实际发生的情况；
- 市场或页面 URL；
- 你的公共钱包地址；
- 订单 ID 或交易哈希（如适用）；
- 近似时间和时区；
- 确切错误消息；
- 去除机密信息的截图或录制。

<Callout type="warning">支持请求中永远不要包含助记词、私钥、认证器密钥、一次性代码、API 密钥或密码。</Callout>

## 需要升级的问题

- 存款或提现在其预期处理时间后仍未解决；
- 市场达到最终结果后领取失败；
- 订单状态和投资组合仓位不一致；
- 你怀疑未经授权访问或恶意签名；
- 市场时间线或争议操作看起来不一致。

对于链上问题，保留交易哈希并在你理解
失败前避免重复操作。
