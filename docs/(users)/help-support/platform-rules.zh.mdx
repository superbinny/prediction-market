## 期望行为

- 不要使用垃圾信息、欺诈、冒充或欺骗行为。
- 不要尝试操纵支持或社区流程。
- 报告市场或交易问题时提供准确背景和证据。
- 遵循运营商条款、市场规则和适用的区域限制。
- 不要共享或请求另一个人的钱包或认证机密。

违规可能导致警告、功能限制、暂停或其他与
严重程度和运营商条款相适应的操作。

## 报告滥用行为

使用官方支持渠道并包含相关 URL、公共钱包地址、
交易哈希、时间戳和脱敏截图。不要与疑似
攻击者对峙或披露私人凭证。
