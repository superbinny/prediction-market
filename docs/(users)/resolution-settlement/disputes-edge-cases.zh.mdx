争议在结果成为最终前挑战提议结果。当预言机流程
活跃时，仓位不可领取且最终结果可能仍然改变。

## 你可能看到的状态

| 状态         | 操作                         |
| ------------ | ---------------------------- |
| **争议窗口** | 审查提议和剩余挑战时间       |
| **已争议**   | 等待挑战被评估               |
| **最终审查** | 监控市场时间线以获得最终结果 |
| **最终**     | 领取可用的获胜仓位           |

当支持时，<SiteName /> 显示链接到预言机流程的**争议**操作。

## 争议前

1. 阅读完整的市场规则。
2. 确认相关日期、时区、阈值和命名来源。
3. 收集直接解决解析标准的公共证据。
4. 遵循争议流程中显示的预言机指示和截止日期。

<Callout type="warning">与市场价格的异议不是错误解析的证据。争议必须解决书面 规则及其解析来源。</Callout>

## 常见边缘情况

- 来源在首次报告后发布更正。
- 事件延迟、取消或超出预期时间完成。
- 标题含糊但详细规则具体。
- 两个平台使用相似标题但标准不同。
- 预言机审查比初始倒计时时间长。

如果时间线不一致，通过市场链接、钱包地址、
相关证据和链上操作失败时的交易哈希联系支持。
