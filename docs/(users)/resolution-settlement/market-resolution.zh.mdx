直接解析预言机（DRO）在链上记录市场的最终结果。<SiteName /> 的
批准解析器检查发布的规则和解析来源，
然后提交官方结果。

社区报告有助于显示预期结果，但它们本身不结算市场。
批准解析器始终做出最终决定。

## 首先阅读解析规则

每个市场定义：

- **解析标准：** 每个结果获胜必须发生什么。
- **解析来源：** 结果必须在何处验证。
- **时间和边缘情况：** 适用的日期、时区、阈值、取消规则或其他
  条件。

<Callout type="warning" title="等待答案可验证">
  过早提交或与书面规则不符的报告可能会损失整个 300 USDC 债券。市场价格、公众意见 和另一个相似的市场不能决定官方结果。
</Callout>

## 解析如何工作

<Steps>
  <Step>
    ### 结果变得可验证

    事件完成或市场规则中的条件得到满足。

  </Step>
  <Step>
    ### 用户可能报告结果

    当解析奖励活跃时，符合条件的用户可以锁定显示的债券并报告 **YES** 或 **NO**。

  </Step>
  <Step>
    ### 站点提交官方结果

    批准解析器验证规则和来源。用户报告是信号；它们不能强制结果。

  </Step>
  <Step>
    ### 领取可用

    获胜份额每份兑换 **$1.00**。解析债券和奖励从
    [设置 → 奖励](/zh/settings/rewards) 单独领取。

  </Step>
</Steps>

## 解析奖励

提案模态框在签名前显示精确债券和奖励。使用当前
默认值，债券为 **300 USDC**，而奖励通常为标准的 **$4.00**，
多市场事件中每个问题 **$1.60**。

| 官方结果                        | 你的债券       | 奖励           |
| ------------------------------- | -------------- | -------------- |
| 你的活跃报告正确                | 全额返还       | 显示的市场奖励 |
| 你的报告不正确                  | 没收至安全储备 | 无             |
| 结果未知、50/50、取消或紧急解析 | 全额返还       | 无             |

<Callout type="info" title="站点不从错误报告中获利">
  没收的债券永远不会去 <SiteName /> 或其解析器。它去用于 安全和奖励系统未来改进的单独安全储备。
</Callout>

### 参与限制

- 每个存款钱包每个市场在其市场整个生命周期中只能报告一次。
- 同时只能有一个活跃 **YES** 报告和一个活跃 **NO** 报告。
- 通过不同钱包报告两边不是无风险的：在 YES 或 NO 结果后，
  一个 300 USDC 债券损失，而正确侧只收到其债券加少量
  显示奖励。
- 报告不能改变侧边。

### 如果市场保持未解析

48 小时后，报告者可以请求返还债券。请求立即放弃
奖励，在另一个 24 小时内保持暴露于官方结果，并且不能
取消。如果在此期间到达结果，正确报告只收到其债券
返还，错误报告损失它。否则，槽位重新开放且只有原始
存款钱包可以领取债券。

## 最终解析后

- 从已解析市场或你的投资组合中领取获胜仓位。
- 从 [设置 → 奖励](/zh/settings/rewards) 领取返还债券和任何赚取的解析奖励。
- 失败份额兑换为 **$0.00**。
