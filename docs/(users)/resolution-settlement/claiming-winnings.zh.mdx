---
title: 领取收益
description: 在市场达到最终结果后兑换获胜份额
---

import { Steps, Step } from 'fumadocs-ui/components/steps'

结果确定后，每份获胜份额可以兑换 $1.00。领取可以从你的投资组合获得，当显示时，从已解析市场的订单面板获得。

## 领取仓位

<Steps>
  <Step>
    ### 查找可领取的市场

    打开**投资组合**并查看收益卡片，或打开已解析市场。

  </Step>
  <Step>
    ### 审查领取

    确认请求中包含的市场和仓位。

  </Step>
  <Step>
    ### 签名

    选择**领取**或**领取收益**，签名请求，等待确认。

  </Step>
  <Step>
    ### 检查你的余额

    确认后，领取金额出现在你的可用交易余额中。

  </Step>
</Steps>

## 收益示例

|                       |     金额 |
| --------------------- | -------: |
| 100 份额以 $0.35 购买 | $35 成本 |
| 获胜兑换              |     $100 |
| **费用前毛利**        |  **$65** |

<Callout type="info">当市场仍处于提议、争议或最终审查状态时，获胜仓位不可领取。</Callout>

如果在最终解析后领取失败，在联系支持前记录市场链接、钱包地址、错误
消息和交易哈希。
