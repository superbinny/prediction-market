预测市场组织为包含一个或多个**市场**的**事件**。每个市场都有可交易的结果，并由自己的订单簿支持。

  <img src="/images/docs/market-structure.svg" alt="一个包含两个事件的市场，每个市场都有连接订单簿的“是”和“否”结果" />
  <figcaption>事件组织相关问题；市场是你交易的基本单位。</figcaption>
</figure>

## 事件与市场的区别

|          | 事件           | 市场                 |
| -------- | -------------- | -------------------- |
| **目的** | 分组相关问题   | 定义一个可交易的问题 |
| **包含** | 一个或多个市场 | 两个或多个结果代币   |
| **示例** | "2028年选举"   | "候选人A会赢吗？"    |

大多数市场是二元的，具有**是（Yes）**和**否（No）**结果。体育和其他部署可能使用诸如团队名称或**上涨/下跌（Up/Down）**的标签，但支付逻辑相同：获胜结果结算为 $1.00，其他结果结算为 $0.00。

## 市场页面上显示的内容

- **规则与解析来源** — 每个结果获胜需要什么
- **价格与图表** — 当前隐含概率和历史走势
- **订单簿** — 每个价格上可用的买单和卖单
- **活动** — 最近的交易和市场更新
- **订单面板** — 结果、订单类型、数量、预估成本和费用

<Callout type="warning" title="交易前阅读规则">
  相似的标题可能有不同的日期、阈值或解析来源。市场规则——而非仅标题——决定获胜结果。
</Callout>

## 交易市场

<Steps>
  <Step>
    ### 查找事件

    浏览类别、按主题搜索或打开共享事件链接。

  </Step>
  <Step>
    ### 选择市场

    对于多市场事件，选择你想要交易的确切问题。

  </Step>
  <Step>
    ### 审查市场

    阅读规则，检查价格和可用流动性，然后选择结果。

  </Step>
  <Step>
    ### 提交订单

    选择市价单或限价单，审查预估总额和费用，然后签名。

  </Step>
</Steps>

## 交易后

成交的份额会出现在你的投资组合中。你可以在结算前出售或持有直到结果确定。在 <SiteName /> 上，当获胜仓位可兑换时，领取操作会出现。
