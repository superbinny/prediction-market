title: 理解价格
description: 了解概率、买单、卖单和价差如何决定成交
---

预测市场上的价格由交易员创造——而不是由运营商设定。买单和卖单在中央限价订单簿（CLOB）中相遇，可用价格随供需而变化。

## 价格即概率

结果份额的交易价格介于 **$0.00** 和 **$1.00** 之间。价格可以解读为市场的隐含概率：

| 份额价格 | 隐含概率 |
| -------- | -------- |
| $0.25    | 25%      |
| $0.50    | 50%      |
| $0.70    | 70%      |

如果你以 $0.40 购买一份份额且它获胜，它将兑换为 $1.00。你的毛利为每份 $0.60（费用前）。失败的份额兑换为 $0.00。

## 订单簿

  <img src="/images/docs/order-book.svg" alt="订单簿显示32分到34分的买单，40分到45分的卖单，以及6分的价差" />
  <figcaption>最佳买单和最佳卖单是最近的可行权价格。</figcaption>
</figure>

| 术语                   | 含义                             |
| ---------------------- | -------------------------------- |
| **买单（Bid）**        | 一个买单；最佳买单是当前最高出价 |
| **卖单（Ask）**        | 一个卖单；最佳卖单是当前最低要价 |
| **价差（Spread）**     | 最佳卖单和最佳买单之间的差额     |
| **中间价（Midpoint）** | 最佳买单和最佳卖单的平均价       |

在示例中，最佳买单为 $0.34，最佳卖单为 $0.40。中间价为 $0.37，但 $0.37 不一定是可执行的：市价买单支付卖单价，而市价卖单获得买单价。

<Callout type="info">
  窄价差通常意味着更好的流动性。大额订单可能消耗多个价格档位，因此其平均成交价可能与第一个显示的价格不同。
</Callout>

## 价格为何变动

- 新信息改变了交易员的估计。
- 已成交的订单从订单簿中移除流动性。
- 新的买单和卖单改善或扩大可用价格。
- 大额订单可能穿过多个价格档位。

当立即执行很重要时使用**市价单**。要设定你愿意接受的最差价格时使用**限价单**。
