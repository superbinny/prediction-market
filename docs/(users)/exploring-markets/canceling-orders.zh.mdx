---
title: 取消订单
description: 从订单簿中移除未成交的限价订单
---

import { Steps, Step } from 'fumadocs-ui/components/steps'

只有开放的未成交限价数量可以被取消。已经成交的订单仍然是
你的仓位和交易历史的一部分。

## 取消一个订单

<Steps>
  <Step>
    ### 打开你的订单

    转到 **投资组合 → 开放订单**。

  </Step>
  <Step>
    ### 查找订单

    按市场、结果、方向或价格定位活跃订单。

  </Step>
  <Step>
    ### 确认取消

    在订单行上选择**取消**，等待其状态更新。

  </Step>
</Steps>

## 取消所有订单

如果该操作对你的账户可用，在开放订单选项卡中选择**取消所有**以
移除已连接钱包的每个活跃订单。

<Callout type="info">订单可能在你取消处理期间成交。检查最终订单状态和你的仓位， 然后提交替换订单。</Callout>
