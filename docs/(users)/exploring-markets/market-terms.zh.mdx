---
title: 市场术语
description: 预测市场和订单簿术语的简明词表
---

当市场页面、订单面板或投资组合中的某个术语不熟悉时，使用此词表。

| 术语                           | 含义                                       |
| ------------------------------ | ------------------------------------------ |
| **事件（Event）**              | 一个包含一个或多个相关市场的容器           |
| **市场（Market）**             | 一个可交易的预测问题                       |
| **结果（Outcome）**            | 市场的侧面，如是、否、上涨、下跌或一个团队 |
| **份额（Share）**              | 结果仓位的一个单位，获胜时结算为 $1.00     |
| **订单簿（Order book）**       | 按价格分组的开放买单和卖单                 |
| **买单（Bid）**                | 买家愿意出价的价位                         |
| **卖单（Ask）**                | 卖家愿意出价的价位                         |
| **价差（Spread）**             | 最佳卖单和最佳买单之间的差额               |
| **中间价（Midpoint）**         | 最佳买单和最佳卖单的平均值                 |
| **流动性（Liquidity）**        | 在当前价格附近可交易的数量                 |
| **滑点（Slippage）**           | 预期价格和平均成交价格之间的差异           |
| **市价单（Market order）**     | 旨在立即成交的订单，依赖可用流动性         |
| **限价单（Limit order）**      | 仅在选定价格或更好价格成交的订单           |
| **解析（Resolution）**         | 从市场规则和预言机流程中确定的最终结果     |
| **争议窗口（Dispute window）** | 可以挑战提议结果的时间段                   |
| **存款钱包（Deposit Wallet）** | 用于余额、授权和链上操作的交易钱包         |

<Callout type="info">"价格"可能指显示的中间价或可执行的买单或卖单。审查订单预估以查看你的交易预期获得的价格。</Callout>
