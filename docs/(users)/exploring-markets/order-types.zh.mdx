每个订单指定一个结果、方向、数量和价格。订单类型控制你是优先考虑立即执行还是等待特定价格。

## 比较订单类型

|                | 市价单                       | 限价单                       |
| -------------- | ---------------------------- | ---------------------------- |
| **执行**       | 立即对可用订单成交           | 仅在你的价格或更好价格成交   |
| **价格控制**   | 最终平均价格取决于订单簿深度 | 你设置最高买单或最低卖单价格 |
| **未成交数量** | 根据 FAK/FOK 偏好取消        | 保持开放直到成交或取消       |
| **最适合**     | 速度                         | 价格控制                     |

## 市价单

市价单以最佳可用价格进行交易。大额订单可能会穿过
多个价格档位，因此在签名前始终审查预估。

在 **设置 → 交易** 中，<SiteName /> 支持两种执行偏好：

- **FAK（成交并取消）：** 立即成交可用数量并取消剩余部分。
- **FOK（全成或取消）：** 立即成交整个订单或完全取消。

## 限价单

限价单仅在你选择的价格或更好价格成交。它可以部分成交，随着匹配
订单的到达。剩余数量保持在 **投资组合 → 开放订单** 中，直到它成交
或你取消它。

<Callout type="info">市价风格订单带有旨在立即执行的执行约束。它仍然依赖于 可用订单簿流动性。</Callout>
